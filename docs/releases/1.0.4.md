# Genetic ChickEngineering 1.0.4

This candidate repairs the Folia startup failure caused by the bundled GuizhanLib
1.8.1 addon lifecycle scheduling its integer tick counter through Bukkit's legacy
scheduler. Only that global bookkeeping callback moves to Folia's native global
scheduler. Paper retains the same initial delay and tick interval.

The counter is cancelled explicitly during plugin shutdown. The general GuizhanLib
scheduler API, machines, recipes, production speeds, energy use, item identities,
configuration and saved data are unchanged.

This repair does not certify cross-region machine gameplay, live-player interactions
or third-party stacking integrations on Folia. Native startup/restart validation is
tracked by Slimefun Legacy's declared-addon admission work.

Ordinary builds are read-only. Publishing requires a manual request, exact version
confirmation and successful compatibility checks; existing releases are never
overwritten. This candidate remains unpublished pending maintainer approval.
